## 参考网站

2026-11-26 使用网页读取工具读取 https://yjsyzt.com/ 首页、面试、五险一金、Offer、合同、清单、补贴页；使用本机 Chrome + Playwright 查看并截图桌面首页、Offer 表单和 390px 手机首页。首轮 `networkidle` 因页面附加网络请求超时，随后 `domcontentloaded` 成功，截图保存在本地 `.work/reference-*.png`。

参考站内容宽约 1120px，居中布局；顶部横排导航；首页分为主工具、辅助入口、指南和使用边界；功能页使用面包屑、说明、复选框/短表单、结果空态、相关工具。社保与公积金分别输入参数；入职清单在本机保存；补贴表单不直接保证资格。手机首页改为纵向排列并保持无横向溢出。

RightStart 沿用“先选工具，再做任务”的架构。用户后续提供的浅蓝参考图用于进一步确定手机首页双列卡片、浅灰背景、主工具/辅助工具分组。原创品牌柱形标识、深蓝/灰蓝色、线性图标、轻边框、原创引导文案与首页流程卡片均独立实现，无复制参考站代码或资产。

## 项目资料与优先级

- 已读 Proposal、技术方案、选题讨论 DOCX，以及课程 Guideline、V3.0 架构 PDF。
- Proposal 最初覆盖条款核验、社保计算与深圳政策；V3.0 文档已将 AI 业务收敛为人才、住房、落户。
- 实际可执行范围以 V4.2 IFPKG 内 `app.yaml` 为准：`advanced-chat`；无 Start 自定义输入；禁用上传；内置十个会话画像/话题变量；具有画像合并、范围路由、市级/区级检索、证据核对、政策回复与补充预审路径。
- 严格不修改现有工作流。Offer、合同、社保及面试模板由前端程序实现；政策咨询使用真实 Chatflow。
- 没有伪造原 Proposal 中尚未落地的逐条自动资格引擎、法律判定、报告结构或当前政策费率。

## 数据与隐私

已有知识库政府资料导入为文章，保留标题、地域、分类、来源和原始片段。卡片只做查询领域与地域筛选，不将用户学历、就业或合同状态自动转换为资格结论。个人条件通过自然语言转交现有 Chatflow 追问；目标区、工作地、企业注册地、社保地分别对待。

无注册账号或用户资料数据库。清单与问题确认标记用 localStorage；AI 内容保留于 React 内存，服务端签名匿名 Cookie 用于用户隔离。查询预填进入聊天后清除地址栏参数。后台服务提供者的日志留存已单独说明。

## 验收范围

功能代码、浏览器实际观察、公式/SSE 单元测试和真实 Dify 测试分开记录，避免将构建通过等同于线上政策正确性。未经用户确认不创建远端仓库、不发布网站。
